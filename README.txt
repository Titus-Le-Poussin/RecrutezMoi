# Recrutez-moi

Bienvenue sur **Recrutez-moi**, un projet personnel développé par Timothée ITHIER.
Ce site web reprend toutes les candidatures envoyées dans le cadre de la recherche d’alternance, sous la forme d’un jobboard dynamique à la HelloWork.

## 🔥 Objectif
Créer un site vitrine interactif autour de mon profil, qui présente :
- Les offres auxquelles j’ai postulé
- Mon profil de candidat (CV, bio, contact)
- Des statistiques personnalisées
- Un espace pour que les entreprises me proposent des offres
- Une section parodique où "je suis le poste" et les entreprises postulent à moi 😄

## ⚙️ Technologies utilisées
- **Frontend** : HTML / CSS (Bootstrap ou Tailwind) / JavaScript
- **Backend** : Python + Flask
- **Données** : Fichier CSV généré depuis Excel
- **Graphiques** : Chart.js ou Plotly

## ✅ Fonctionnalités clés
- Import automatique d’un fichier CSV des candidatures
- Affichage dynamique des offres sous forme de cartes
- Filtres par ville, fonction, type de contrat
- Redirection vers les vraies offres (HelloWork, Indeed…)
- Statistiques de suivi de candidature
- Pages personnelles (CV, bio, réseaux sociaux)
- Formulaire de contact pour recruteurs intéressés
- Offres "custom" où je suis le poste 😎
